# MYANMAR Map — Spec

Global Monopoly ဂိမ်းထဲကို **MYANMAR** ဆိုတဲ့ မြေပုံအသစ် တစ်ခု ထပ်ထည့်ရန်။

> ⚠️ **အရေးကြီး** — ဒီ spec ထဲက feature အားလုံးဟာ **MYANMAR မြေပုံအတွက်သာ**။
> ရှိပြီးသား World မြေပုံကို လုံးဝ မထိရ။ မြေပုံ ရွေးတဲ့အခါ MYANMAR ရွေးမှ
> ဒီစည်းကမ်းတွေ အလုပ်လုပ်ရမယ်။

---

## ၁. ဘုတ် အကျဉ်းချုပ်

| | |
|---|---|

| ဝယ်လို့ရတဲ့ကွက် | **၃၃** (မြို့ ၂၅ + သယ်ယူပို့ဆောင်ရေး ၄ + ကုမ္ပဏီ ၄) |
| အုပ်စု | **၉** |

### ငှားခ တွက်နည်း

```
အခြေခံငှားခ = ဈေး ÷ ၁၀

အုပ်စု မပြည့်သေး      →  အခြေခံ × ၁
အုပ်စု ပြည့် (အိမ်မရှိ) →  အခြေခံ × ၂
အိမ် ၁ လုံး           →  အခြေခံ × ၄
အိမ် ၂ လုံး           →  အခြေခံ × ၇
အိမ် ၃ လုံး           →  အခြေခံ × ၁၁
အိမ် ၄ လုံး           →  အခြေခံ × ၁၅
ဟိုတယ်               →  အခြေခံ × ၂၀
```

**ဥပမာ — Mandalay (၇၄၀ သိန်း)**
အခြေခံ ၇၄ → ပြည့် ၁၄၈ → အိမ်၁ ၂၉၆ → အိမ်၂ ၅၁၈ → အိမ်၃ ၈၁၄ → အိမ်၄ ၁,၁၁၀ → ဟိုတယ် ၁,၄၈၀

အိမ်ဆောက်ရာမှာ **အုပ်စုအတွင်း တန်းတူ ဆောက်ရမယ်** (ရှိပြီးသား စည်းကမ်းအတိုင်း)။

## ၇. Feature ၁၁ ခု

### ၇.၁ 🪖 စစ်မှုထမ်း (Jail စနစ် အစား)

**ဘယ်လို ရောက်လဲ**
- `ခေါ်စာရောက်ပြီ` ထောင့် ဆိုက်
- ကံစမ်းမဲမှာ **ခေါ်စာ** ထွက်
- အန်စာ တူတူ ၃ ကြိမ် ဆက်ကျ

**ထွက်နည်း ၅ ခု — ရောက်တဲ့အခါ ရွေးခိုင်းရမယ်**

| နည်းလမ်း | ကုန်ကျ | အကျိုးဆက် |
|---|---|---|
| 💵 ငွေပေး ရှောင် | လက်ကျန်ငွေရဲ့ **၁၀%** (အနည်းဆုံး ၅၀၀ သိန်း) | ချက်ချင်း လွတ် |
| 🏚️ ရှောင်ပုန်း | အခမဲ့ | အလှည့် **၂** ခု ကျော်။ **ငှားခ မကောက်ရ** |
| 🛂 ထွက်ပြေး | **၈၀၀ သိန်း** | မူဆယ်နယ်စပ်ဂိတ် ကွက်ကို ရွှေ့။ အလှည့် **၁** ခု ကျော်။ **ငှားခ ကောက်လို့ရ** |
| 🪖 တက် | အခမဲ့ | အလှည့် **၃** ခု ကျော်။ ငှားခ မကောက်ရ။ ပြန်လာရင် ၃၀၀ သိန်း ရ |
| 🙏 ကုသိုလ် သုံး | ကုသိုလ် ၁ မှတ် | ချက်ချင်း လွတ် |

**အရေးကြီး:** စစ်မှုထမ်းအတွင်း **ငှားခ မကောက်ရ** (ထွက်ပြေးသူက လွဲလို့)။ ဒါက Monopoly ရဲ့ Jail နဲ့ အဓိက ကွာတဲ့အချက် — Jail က အကာအကွယ် ဖြစ်တတ်ပေမဲ့ ဒါက တကယ် နာရမယ်။

---

### ၇.၂ 🙏 အလှူ / ကုသိုလ်

ဘုရားကွက် ၃ ခု — **ရွှေတိဂုံ / ကျိုက်ထီးရိုး / မဟာမုနိ**

```
ဆိုက်ရင်  →  ၂၀၀ သိန်း လှူလို့ရတယ် (မလှူလည်း ရတယ်)
          →  လှူရင် ကုသိုလ် ၁ မှတ် ရ

ကုသိုလ် ၁ မှတ်နဲ့ လုပ်လို့ရတာ (အချိန်မရွေး):
   • စစ်မှုထမ်းက ချက်ချင်း လွတ်
   • ငှားခ ၁ ကြိမ် မပေးဘဲ ကျော်
   • ကံစမ်းမဲ ဆိုးတစ်ခု ချေဖျက်
```

အများဆုံး ကုသိုလ် ၃ မှတ်ပဲ သိမ်းလို့ရမယ်။

### ၇.၃ 🏢 ကုမ္ပဏီနဲ့ တွဲတဲ့ Event

| Event ကတ် | ဖြစ်မယ့်အရာ |
|---|---|
| **မီးပျက်** | ဒီ round မှာ မြို့အားလုံး ငှားခ **၅၀% ကျ**။ ⚡ YESC ပိုင်သူက **ဝင်ငွေ ၂ ဆ** ရ |
| **အင်တာနက် ဖြတ်** | ဒီ round မှာ ဘယ်သူမှ **trade / loan မလုပ်ရ**။ 📱 MPT ပိုင်သူက လွတ် |
| **ဓာတ်ဆီ ပြတ်** | ကစားသူတိုင်း အလှည့် **၁** ခု ကျော်။ ⛽ Denko ပိုင်သူက ကျော်စရာမလို |
| **ငွေကြေးဖောင်းပွ** | အပိုင်း ၇.၄ ကြည့်။ 🏦 KBZ ပိုင်သူက သက်ရောက်မှု မခံရ |

### ၇.၄ 💸 ငွေကြေးဖောင်းပွမှု

```
Round ၅ ခု ပြီးတိုင်း  →  မြို့အားလုံး ငှားခ ၁၀% တက်
                      →  လက်ထဲက ပိုက်ဆံ တန်ဖိုး မတက်ဘူး
```

ပိုက်ဆံ ပုံထားရင် ရှုံးတယ်၊ မြေဝယ်ရင် နိုင်တယ်။ ပွဲကိုလည်း မြန်မြန် ပြီးစေတယ်။
UI မှာ လက်ရှိ ဖောင်းပွနှုန်း (ဥပမာ `+၃၀%`) ပြထားပေးပါ။

### ၇.၅ 🌍 ငလျင်

```
Event ကတ် "ငလျင်လှုပ်"  →  အန်စာ ၁ လုံး လှိမ့်
   ၁ / ၃ / ၅  →  မန္တလေး အုပ်စု အိမ်/ဟိုတယ် အားလုံး ပြုတ် (ပြန်ပိုက်ဆံ မရ)
   ၂ / ၄ / ၆  →  အညာ အုပ်စု အိမ်/ဟိုတယ် အားလုံး ပြုတ်
```

### ၇.၆ 💰 ငွေကြေး — ကျပ် (သိန်း)

`$` အစား **သိန်း** သုံးရမယ်။ ဥပမာ `၈၃၀ သိန်း`။
မြို့နာမည်နဲ့ ကတ်စာသားတွေကို **မြန်မာ / English ပြောင်းခလုတ်** ထည့်ပေးပါ။

```
ပိုင်ရှင်ကို ၂၀ သိန်း ပေးရမယ်။
```

ပိုင်ရှင် မရှိရင် မပေးရဘူး။ ကိုယ်ပိုင်တာဆိုလည်း မပေးရဘူး။

### ၇.၈ 🎫 အောင်ဘာလေ ထီ

```
ကံစမ်းမဲ "ထီထိုးမလား?"  →  ၁၀ သိန်း ပေးပြီး ထိုးလို့ရတယ် (မထိုးလည်း ရ)
   အန်စာ ၂ လုံး လှိမ့်
      ၁၂      →  ၃,၀၀၀ သိန်း
      ၁၀–၁၁   →    ၅၀၀ သိန်း
      ၇–၉     →    ၁၀၀ သိန်း
      ၂–၆     →      ဘာမှ မရ
```

### ၇.၉ 🏚️ ရပ်ကွက် လှူဒါန်းပွဲ (အိုး)

```
အခွန် / ဒဏ်ကြေး ပေးတိုင်း  →  ပိုက်ဆံက ဘုတ်အလယ် အိုးထဲ စုတယ်
🏚️ ရှောင်တိမ်းရာ ထောင့် ဆိုက်သူ  →  အိုးထဲက အကုန် ယူတယ်
```

အိုးထဲ ဘယ်လောက်ရှိလဲ ဘုတ်အလယ်မှာ အမြဲ ပြထားပေးပါ။

```
စစ်မှုထမ်းက "ထွက်ပြေး" ရွေးထားသူ  →  နယ်စပ်မှာ ရှိနေစဉ်
                                  round တိုင်း ၂၀၀ သိန်း ရ
```

### ၇.၁၁ 💰 ချေးငွေ (Loan) — အခက်ဆုံး feature

**တောင်းခံခြင်း** — Trade UI ပုံစံ။ **အချိန်မရွေး** တောင်းလို့ရမယ် (ကိုယ့်အလှည့် မဟုတ်လည်း ရ)။

```
တောင်းခံချက်မှာ ပါရမယ့်အရာ:
   ပမာဏ          (ဥပမာ ၅၀၀ သိန်း)
   အတိုးနှုန်း     (round တစ်ခုလျှင် % — ချေးသူက သတ်မှတ်၊ ပို့မပြီးခင် ညှိလို့ရ)
   သက်တမ်း       (round အရေအတွက်)
   အပေါင်မြေ      ← မဖြစ်မနေ ထည့်ရမယ်

ချေးပေးသူက  လက်ခံ / ငြင်း / ပြန်ညှိ(counter)
```

**အတိုး — ရိုးရိုးအတိုး (simple interest)**

```
အကြွေး = အရင်း + (အရင်း × အတိုးနှုန်း × ကျော်သွားတဲ့ round)
```

**ကန့်သတ်ချက် ၃ ခု — မပါမဖြစ်**

```
၁.  အတိုးနှုန်း အမြင့်ဆုံး  round တစ်ခုလျှင် ၂၀%
၂.  အကြွေး စုစုပေါင်း အများဆုံး  အရင်းရဲ့ ၃ ဆ  (ရောက်ရင် အတိုး ရပ်)
၃.  အပေါင်မြေ မဖြစ်မနေ။ အပေါင်ထားတဲ့ မြေမှာ အိမ် မဆောက်ရ
```

**ပြန်ဆပ်ခြင်း**
- ကိုယ့်အလှည့်မှာ အချိန်မရွေး ဆပ်လို့ရတယ်
- **Start ဖြတ်တိုင်း** အကြွေးရဲ့ ၂၅% အလိုအလျောက် နုတ်တယ် (ပိုက်ဆံ ရှိရင်)
- သက်တမ်းပြည့်လို့ မဆပ်နိုင်ရင် → **အပေါင်မြေ ချေးပေးသူလက် ရောက်**
- ချေးသူ ဒေဝါလီခံရင် → ချေးပေးသူက **ဘဏ်ထက် အရင်** အပေါင်မြေ ရတယ်

**UI မှာ လိုမယ့်အရာ**
- လက်ရှိ အကြွေးစာရင်း (ဘယ်သူ့ဆီက ဘယ်လောက်၊ အတိုးနှုန်း၊ ကျန်ရက်)
- Round တိုင်း အတိုး အလိုအလျောက် တွက်ပြီး update
- အပေါင်မြေကို ဘုတ်ပေါ်မှာ အမှတ်အသား ပြ

## ၈. ကတ် စာရင်း

### ကံစမ်းမဲ (Chance)

```
ရပ်ကွက်ကနေ စစ်မှုထမ်း စာရင်းတင်လိုက်ပြီ    →  စစ်မှုထမ်းစခန်းသို့
ပွဲစားက ဖုန်းဆက်လာတယ်                    →  ၅၀၀ သိန်း ပေးရင် စာရင်းက ထွက်
ခေါ်စာ ကင်းလွတ်ခွင့် ရတယ်                  →  ကတ် သိမ်းထား၊ နောင် သုံး
ထီထိုးမလား?                              →  အပိုင်း ၇.၈
ဘုရားပွဲ လှူဒါန်း                          →  ၁၀၀ သိန်း ပေး၊ ကုသိုလ် ၁ မှတ် ရ
ရန်ကုန် ယာဉ်ကြောပိတ်                      →  ၃ ကွက် နောက်ပြန်
ဆေးရုံစရိတ်                               →  ၂၀၀ သိန်း ပေး
အရှေ့ဆုံး လေဆိပ်သို့ သွား                   →  ဆိုက်ရင် ငှားခ ၂ ဆ ပေးရ
Start သို့ ပြန်သွား                        →  ၅၀၀ သိန်း ရ
```

### သတင်း (Event)

```
မီးပျက်                                   →  အပိုင်း ၇.၃
အင်တာနက် ဖြတ်                             →  အပိုင်း ၇.၃
ဓာတ်ဆီ ပြတ်                               →  အပိုင်း ၇.၃
ငွေကြေးဖောင်းပွ                            →  အပိုင်း ၇.၄
ငလျင် လှုပ်                                →  အပိုင်း ၇.၅
ခရီးသွား ရာသီ                              →  ရခိုင် + ရှမ်း အုပ်စု ဒီ round ငှားခ ၂ ဆ
ဆန်ဈေး တက်                                →  မြစ်ဝကျွန်းပေါ် အုပ်စု ဒီ round ငှားခ ၂ ဆ
နယ်စပ် ကုန်သွယ်မှု ပိတ်                      →  🛂 နယ်စပ်ဂိတ် ဒီ round ဝင်ငွေ မရ
ရပ်ကွက် လှူဒါန်းပွဲ                          →  ကစားသူတိုင်း ၅၀ သိန်း စီ အိုးထဲ ထည့်
```
