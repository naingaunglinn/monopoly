## ၁. 🇹🇭 ထောင့်နာမည် ပြောင်း

```
ရှောင်တိမ်းရာ  →  ချင်းမိုင် (Chiang Mai)
```

လုပ်ဆောင်ချက် မပြောင်း — ရပ်ကွက်လှူဒါန်းပွဲ အိုး ယူရမယ့်နေရာ၊ ပြီးတော့
စစ်မှုထမ်းက "ထွက်ပြေး" ရွေးသူ ရောက်သွားမယ့် နေရာလည်း ဖြစ်တယ်။

## ၂. 🏢 ကုမ္ပဏီ — ၄ ခုမှ ၅ ခု

**Brycen Myanmar** (IT ကုမ္ပဏီ) ထပ်ထည့်မယ်။ ဈေး ၂၅၀ သိန်း (ကျန်ကုမ္ပဏီတွေနဲ့ အတူတူ)။

**ဘုတ်မှာ နေရာ** — ကွက် **၄၁** က `အခွန်ထူး — ၅၀၀ သိန်း` ကို ဖြုတ်ပြီး အစားထိုး။
(ဝင်ငွေခွန် ကွက် ၁၀ ကတော့ ကျန်နေသေးတယ်။ ဘုတ် စုစုပေါင်း **၄၈ ကွက်** အတိုင်းပဲ။)

```
41  🏢 Brycen Myanmar        ၂၅၀      ← အရင်က အခွန်ထူး ဖြစ်ခဲ့တဲ့နေရာ
```

**ငှားခ ဇယား အသစ်** (ကုမ္ပဏီ ၅ ခု ဖြစ်သွားလို့ အဆင့် ၅ ဆင့်)

| ပိုင်တဲ့ ကုမ္ပဏီ | ငှားခ |
|---|---|
| ၁ | အန်စာပေါင်းလဒ် × ၂၅ |
| ၂ | × ၅၀ |
| ၃ | × ၁၀၀ |
| ၄ | × ၂၀၀ |
| **၅ ခုလုံး** | **× ၄၀၀** |

ဝယ်လို့ရတဲ့ကွက် စုစုပေါင်း = မြို့ ၂၅ + သယ်ယူ ၄ + ကုမ္ပဏီ ၅ = **၃၄**

## ၃. 📜 ကံစမ်းမဲ ကတ် ၂ ခု ထပ်ထည့်

```
📜 ပေါ်တာ ဆွဲခံရပြီ
   →  ချက်ချင်း စစ်မှုထမ်းစခန်းသို့ သွား
   →  ထွက်နည်း တစ်ခုတည်းပဲ ရှိတယ်: ၅၀၀ သိန်း ပေး
   →  ရှောင်ပုန်း / ထွက်ပြေး / တက် / ကုသိုလ် — ဘာမှ မသုံးရ

📜 Brycen Myanmar အရှုံးပေါ်
   →  ကုမ္ပဏီကို ကူညီရမယ်ဆိုပြီး ကစားသမား တိုင်းက
      Brycen Myanmar ပိုင်ရှင်ကို ၁၀၀ သိန်းစီ ပေးရမယ်
   →  ပိုင်ရှင်က ကဒ်ထုတ်သူ ဖြစ်ရင်လည်း ကျန်သူတွေဆီက ကောက်ရတယ်
   →  ဘယ်သူမှ မပိုင်သေးရင် ကစားသမားတိုင်း ၁၀၀ သိန်းစီ
      ရပ်ကွက်လှူဒါန်းပွဲ အိုးထဲ ထည့်
```

## ၄. 📰 သတင်း ကတ် ၁ ခု ထပ်ထည့်

```
📰 ပေါ်တာ လိုက်ဖမ်းနေတယ်
   →  ကစားသမား တစ်ယောက်ကို ကျပန်း ရွေး (ကဒ်ထုတ်သူ အပါအဝင်)
   →  အဲ့ဒီလူ စစ်မှုထမ်းစခန်းသို့ ချက်ချင်း သွား
   →  ထွက်နည်း ပုံမှန် ၅ ခု အကုန် သုံးလို့ရတယ်
```

## ၅. 🎖️ ရာထူးစနစ် (ဗိုလ်ချုပ်) — အသစ်

မူရင်း spec အပိုင်း ၇.၁ ရဲ့ **"🪖 တက် (အမှန်တကယ် သွား)"** ရွေးချယ်မှုကို ချဲ့တာ။

### ၅.၁ ရာထူး တက်ခြင်း

```
"တက်" ရွေးပြီး  အလှည့် ၃ ခု  ကျော်ပြီးတာနဲ့
      ↓
အံစာ ၁ လုံး လှိမ့်
      စုံကိန်း (၂/၄/၆)  →  ရာထူး +၂
      မကိန်း  (၁/၃/၅)  →  ရာထူး +၁
      ↓
လစာ ရတယ် =  ရာထူးအဆင့် × ၂၀၀ သိန်း   (ဘဏ်က ပေး)
      ဥပမာ ရာထူး ၄ ရောက်သွားရင် ၈၀၀ သိန်း

ရာထူး အမြင့်ဆုံး = ၆
ရာထူးက စခန်းက ထွက်သွားလည်း မပျက်ဘူး (တစ်သက်လုံး ကျန်တယ်)
```

> ⚠️ လစာက **ပုံသေ** ဖြစ်ရမယ် — လက်ရှိပိုက်ဆံရဲ့ % **မသုံးရ**။
> % သုံးရင် ချမ်းသာသူပဲ ပိုချမ်းသာပြီး ပွဲပျက်မယ်။

### ၅.၂ ဗိုလ်ချုပ် — တစ်ယောက်တည်းပဲ ရှိရမယ်

```
ရာထူး အမြင့်ဆုံး ကစားသမား တစ်ယောက်တည်းက  🎖️ ဗိုလ်ချုပ်
   • ရာထူး ၄ အောက်ဆိုရင် ဘယ်သူမှ ဗိုလ်ချုပ် မဖြစ်ရ
   • သရေကျရင်  →  အရင်ရောက်သူက ဆက်ထိန်း
   • တစ်ယောက်ယောက်က ကျော်တက်ရင်  →  အာဏာ ပြောင်း၊ ဒါပေမဲ့ အရင်သူ့ရာထူး မပျက်
```

### ၅.၃ ဗိုလ်ချုပ် အာဏာ

**ရာထူး ၄ ကစပြီး** သုံးလို့ရတယ်။ **Round ၂ ခုလျှင် ၁ ကြိမ်** သာ။

```
အာဏာ သုံးရင်  →  အံစာ ၂ လုံး လှိမ့်

   ၈ အောက်  →  ကြိုက်တဲ့ ကစားသမား ၁ ယောက်ဆီက ၁,၀၀၀ သိန်း တောင်းယူ
   ၈ အထက်  →  ကြိုက်တဲ့ ကစားသမား ၁ ယောက်ရဲ့ မြေ ၁ ကွက် သိမ်းယူ
                (ဖျက်တာ မဟုတ်ဘူး — ဗိုလ်ချုပ် လက်ထဲ ရောက်သွားတာ)
                ✗ အိမ်/ဟိုတယ် ဆောက်ထားတဲ့ မြေကို မသိမ်းရ
```

**ခံရသူက ကုသိုလ် ၂ မှတ် သုံးပြီး တစ်ကြိမ် တားလို့ရတယ်။**

## ၆. 😠 မကျေနပ်မှု ခွက် (Unrest) — အသစ်

ဗိုလ်ချုပ်ကို ထိန်းတဲ့ စနစ်။ **မပါမဖြစ်** — မပါရင် ဗိုလ်ချုပ်က မနိုင်တော့ဘူး။

### ၆.၁ ခွက်

```
ဗိုလ်ချုပ် မဟုတ်တဲ့ ကစားသမား တစ်ယောက်စီ  →  မကျေနပ်မှု ခွက် ၂ ခု
စုစုပေါင်း ၃ ခု သုံးပြီးတာနဲ့  →  ဗိုလ်ချုပ် ဖြုတ်ချခံရ
```

### ၆.၂ ဘယ်လို သုံးလဲ

```
ဗိုလ်ချုပ် အာဏာ သုံးလိုက်တိုင်း
      ↓
"မကျေနပ်မှု ပြမလား?" window ပွင့် (၂၀ စက္ကန့်)
      ↓
ဗိုလ်ချုပ်မှလွဲ၍ ကစားသမား တိုင်း ဆုံးဖြတ် — သုံးမလား / မသုံးဘူးလား
      ↓
ဘယ်သူ သုံးလဲ အားလုံးကို ဖွင့်ပြ   (v1 မှာ ဖွင့်ပြ၊ လျှို့ဝှက်တာက v2)
      ↓
စုစုပေါင်း ၃ ခု ပြည့်တာနဲ့  →  🔥 ဗိုလ်ချုပ် ချက်ချင်း ပြုတ်
```

> **အရေးကြီး** — ခံရသူ တစ်ယောက်တည်းပဲ ဒေါသထွက်တာ မဟုတ်ဘူး။
> ကျန်သူတွေက ပြိုင်ဘက် နာသွားတာကို ကျေနပ်ပြီး **မသုံးဘဲ သိမ်းထားလို့ရတယ်**။
> ဒါကြောင့် ဗိုလ်ချုပ်က ဘယ်သူ့ကို ထိရမလဲ တွက်ရတယ် — ဒါက ဒီ feature ရဲ့ အနှစ်သာရ။

### ၆.၃ 💰 လာဘ်ပေးခြင်း

```
ဗိုလ်ချုပ်က အာဏာ မသုံးခင် ကစားသမားတစ်ယောက်ကို ပိုက်ဆံ ကမ်းလှမ်းလို့ရတယ်
      ("ငါ့ကို မကျေနပ်မှု မသုံးရင် ၅၀၀ သိန်း ပေးမယ်")
လက်ခံရင်  →  အဲ့ဒီ အသုံးပြုမှုမှာ သူ့ခွက် မသုံးရတော့ဘူး
```

Trade UI ရှိပြီးသားဖြစ်လို့ အသစ် သိပ်မလုပ်ရဘူး။

### ၆.၄ ပြန်ရခြင်း

```
ဗိုလ်ချုပ် ဖြုတ်ချခံရတာနဲ့  →  သုံးပြီးသား ခွက် အားလုံး ပြန်ရ
                              (ဖြုတ်ချခံရသူရဲ့ ရာထူး အားလုံး ပျက်)
```

### ၆.၅ ဥပမာ (၄ ယောက်ပွဲ)

```
ကလောက်လေး = ဗိုလ်ချုပ် (ရာထူး ၄)
gray / Xin / Billy  =  တစ်ယောက်စီ ခွက် ၂   (စုစုပေါင်း ၆)

အသုံး ၁  Xin ဆီက ၁,၀၀၀ သိန်း တောင်း
         → Xin ခွက် ၁ သုံး                        စုစုပေါင်း ၁/၃
         → gray, Billy က ပျော်နေလို့ မသုံးဘူး

အသုံး ၂  Billy ရဲ့ မြေ သိမ်း
         → Billy ခွက် ၁ သုံး                      စုစုပေါင်း ၂/၃
         → gray ကို ၅၀၀ သိန်း လာဘ်ပေး → gray မသုံးဘူး

အသုံး ၃  gray ဆီက ၁,၀၀၀ သိန်း တောင်း   ← မှားပြီ
         → gray ခွက် သုံး                        စုစုပေါင်း ၃/၃
         → 🔥 ဗိုလ်ချုပ် ပြုတ်
```

## ၈. ဦးစားပေး

မူရင်း spec ရဲ့ အဆင့် ၄ ဆင့်ထဲမှာ ဒီလို ထည့်ပါ —

| အဆင့် | ထပ်ဖြည့်ရမယ့်အရာ |
|---|---|
| **၁** | ချင်းမိုင် နာမည် · Brycen Myanmar ကုမ္ပဏီ · ကုမ္ပဏီ ငှားခ ၅ ဆင့် |
| **၂** | ပေါ်တာ ကဒ် ၂ ခု · Brycen အရှုံးပေါ် ကဒ် |
| **၃** | ရာထူးစနစ် + ဗိုလ်ချုပ် အာဏာ + မကျေနပ်မှု ခွက် |
| **၄** | (မူရင်းအတိုင်း — ချေးငွေ) |

> ရာထူးစနစ်နဲ့ မကျေနပ်မှုက **တွဲနေတယ်** — တစ်ခုတည်း မထည့်ရဘူး။
> မကျေနပ်မှု မပါဘဲ ဗိုလ်ချုပ် ထည့်ရင် ပွဲပျက်မယ်။
